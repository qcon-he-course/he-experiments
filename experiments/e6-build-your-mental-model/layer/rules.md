# Diagrams and notes

- The one exception to not creating files: diagrams and notes go under `.harness/` in the repository (`.harness/diagrams/` and `.harness/notes/`). Git ignores that folder. Create nothing anywhere else.
- Draw diagrams with the archify skill and its `archify` command. Every participant and every arrow comes from code you opened or a tool result, with its file and line.
