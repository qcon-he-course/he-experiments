## 1. What is this project about? How do I get started?

**Spring PetClinic** is a sample Spring Boot application that demonstrates best practices for building a veterinary clinic management system. It manages owners, their pets, and vet visits.

To get started:
```bash
./mvnw spring-boot:run
```
Then visit http://localhost:8080/

## 2. Default database when starting with no options

**H2** (in-memory database) is the default. This is configured in `/work/src/main/resources/application.properties` line 2:
```properties
database=h2
```

H2 is chosen because it requires no external setup—the schema and sample data are applied automatically on first run.

## 3. Vet list cache duration

**10 minutes**. According to the README, the vet list is refreshed from the database every 10 minutes. The `VetRepository.findAll()` uses `@Cacheable("vets")` annotation and the cache is configured in `CacheConfiguration:37`, though the specific TTL of 10 minutes is stated in the documentation.

## 4. Can Jean Coleman add another pet called "max"?

**Yes**. Jean Coleman already has a pet called "Max" (capital M, visible in `data.sql` line 43). But pet names are **case-sensitive** (stated in README line 66), so "max" (lowercase) is a different pet and can be added as a separate entry.

## 5. Search owners for "davis" (all lowercase)

You'll see **both Betty Davis and Harold Davis** in the results. Although the README states "Owner search is case-sensitive," the H2 database (the default) performs case-insensitive LIKE queries. The query in `OwnerController:145` calls `findByLastNameStartingWith("davis", pageable)`, which executes a LIKE query that will match both "Davis" entries.
