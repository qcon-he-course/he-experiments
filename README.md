# he-experiments

The experiments of the InfoQ Certified AI-Assisted Engineering Program, one folder per week. Each week's folder has its own README, setup page, scripts and our stored results, so you can run the experiments again on your own Claude plan.

| Week | Folder | What it covers |
|---|---|---|
| 1 | [week-1/](week-1/) | Understanding a codebase you didn't write: the same six questions about a seeded PetClinic, asked at each rung of a ladder of harness layers |

Clone it once:

```bash
mkdir -p ~/course
git clone https://github.com/qcon-he-course/he-experiments.git ~/course/he-experiments
```

Then start with [week-1/SETUP.md](week-1/SETUP.md). To get later weeks: `git -C ~/course/he-experiments pull`.
